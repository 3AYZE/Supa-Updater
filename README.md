# SupaUpdater

SupaUpdater is a free Windows software and optional-driver updater with a compact Windows/Fluent-inspired interface.

## Core features
- Scan supported installed software with WinGet.
- Select individual updates or install all available updates after confirmation.
- Review optional Windows Update driver packages separately.
- Persistent update results and activity.
- System, Light and Dark appearance.
- GitHub release checking and confirmed self-update support.
- Dedicated SupaUpdater desktop, taskbar, Alt+Tab and EXE icon.

## Windows release
Download both `SupaUpdater.exe` and `SupaUpdaterUpdateHelper.exe` from the same release and keep them in the same folder. The helper performs confirmed executable replacement after SupaUpdater closes.

Driver updates require Windows Update and explicit confirmation. Firmware/BIOS updates are intentionally excluded.

## Source edition
Install Python 3.10+ and WinGet, extract the source archive, and run `app.pyw`.

The SupaUpdater icon is original project artwork with a Fluent-inspired visual treatment; it does not use the Microsoft or Windows logo.
